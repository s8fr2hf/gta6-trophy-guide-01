Leonida Trophy Guide — an offline checklist and roadmap for all 55 GTA 6 trophies (1 platinum, 2 gold, 6 silver, 46 bronze), with a guide in plain words for every trophy, a 6-stage roadmap, a missable warning for the one trophy that can be missed (Positive Mental Attitude, first meditation in Chapter 1), spoiler controls, and progress tracking that stays on your device.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

That builds the dossier into `out/`. To browse the guide itself, serve the `app/` directory with any static file server and open `index.html`.
